# AI 外汇战士大赛（AI FX Contest）

> 8 个顶尖大模型，每人 100 万日元本金、最高 25 倍杠杆，在 2024 年全年真实的 USD/JPY 日线（262 个交易日）里纯看 K 线交易一整年——谁能帮“久留美”赚回 2000 万，谁才是真正的“韭留美”？

本仓库公开视频中承诺的全部实验材料：**真实与脱敏行情数据、冻结规则与提示词模板、8 位 AI 全年 2,096 次每日原始输出、撮合结算与统计脚本**，便于核验与复现。

> **免责声明**：本项目为基于历史数据的 AI 娱乐实验，**不构成任何投资建议**，不涉及任何真实交易平台。杠杆放大收益，也同样放大风险。

## 核心实验设定

- **行情区间**：2024 年全年真实 USD/JPY 日线，共 262 个交易日（`pipeline/data/usdjpy-2024.csv`）。
- **脱敏防泄露**：日期替换为“第 N 天”，价格整体线性缩放（首日开盘归 100），不提供新闻、日期或技术指标，只给每天的 OHLC 四个数。
- **纯净隔离会话**：每位 AI 每天收盘后新开独立会话，仅携带账户状态、近 60 根脱敏 K 线与最近 5 天自己的独白；次日开盘成交，全年 2,096 次决策 0 次格式错误。
- **风控规则**：杠杆 1–25 倍自选，支持止损/止盈（按日内高低价触发），维持保证金跌破 50% 强制平仓，含固定点差与隔夜掉期成本（见 `pipeline/config/rules.json`）。

## 目录结构

```text
.
├── PLAN.md                 # 项目计划与规则定稿
├── RUNBOOK.md              # 冻结 sha256 校验与运行记录
└── pipeline/
    ├── config/             # 规则、选手、历史事件、奖项与行情配置
    ├── data/               # 2024 年 USD/JPY 原始日线数据
    ├── src/
    │   ├── engine.ts       # 撮合与保证金强平结算引擎
    │   ├── market.ts       # 行情读取与线性脱敏变换
    │   ├── task.ts         # 每日提示词模板（一字不改发给 8 位选手）
    │   ├── run-season.ts   # 逐日驱动主程序
    │   ├── channels.ts     # 4 大 CLI 渠道隔离调用配置
    │   ├── baselines.ts    # 6 个基线机器人
    │   └── awards.ts       # 统计与奖项自动计算
    ├── runs/               # 8 位 AI 选手全年每日原始输出与 state.json
    └── out/                # 汇总统计（stats.json）与奖项（awards.json）
```

```bash
node pipeline/src/awards.ts
```
